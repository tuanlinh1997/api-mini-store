# docs/stakeholders/ — Folder Rules

**Owner**: @documentation-writer
**Purpose**: Plain-language project information for non-technical stakeholders.

| File | What it is | Who edits |
|------|-----------|-----------|
| `STAKEHOLDER_BRIEF.md` | What the product is, goals, scope, status, timeline, decisions needed | @documentation-writer |

## Rules

- No jargon, no codenames, no technical detail — if a stakeholder would have to ask what a word means, replace the word.
- Update Status and What's New after every shipped feature or milestone.
- It's a brief, not an archive — prune old entries on every update.
- New files here require updating this table and the map in `docs/AGENTS.md`.
